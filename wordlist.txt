# Nudge Wordlist
# One regex pattern per line
# Lines starting with # are comments
# Patterns are matched case-insensitively against subtitle text
#
# Tips:
#   \b = word boundary (prevents "hell" matching "hello")
#   .* = any characters
#   (a|b) = either a or b
#
# Examples:
#   \bfuck\b        - matches "fuck" as whole word
#   \bf+u+c+k+\b    - matches "fuuuck", "ffffuck", etc.
#   \bshit\b        - matches "shit" as whole word
#   god\s*damn      - matches "god damn", "goddamn"
